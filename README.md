# FunScripts

Two small, self-contained Python toys. No dependencies, no setup — just run.

## 🖥️ binary_analyzer.py

Shows live binary patterns of running processes in your terminal.

```bash
python3 binary_analyzer.py
```

What it does: reads `ps aux`, finds running processes, and renders each
process's PID as a binary pattern. A calm, visual way to watch what your
machine is doing.

## 🌧️ matrix.py

Digital rain — the classic Matrix falling-code effect, right in your terminal.

```bash
python3 matrix.py
```

Pure stdlib (`random`, `time`, `sys`). Terminal-sized, no install.
